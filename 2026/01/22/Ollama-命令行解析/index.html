Ollama 命令行解析

发表于 2026-01-22 分类于 技术分享

🧠 Ollama 命令行解析

Ollama 是一个用于在本地运行大语言模型（LLM）的工具。下面为你逐条解析每个命令的作用：

📋 核心命令解析

1. ollama serve

  • 作用：启动 Ollama 服务端。
  • 说明：这是后台服务进程，必须先运行它，其他命令（如 run、pull）才能正常工作。通常在终端中执行后，会保持运行状态，你需要新开一个终端来执行其他命令。

2. ollama create

  • 作用：基于模型文件或 Modelfile 创建一个自定义模型。
  • 说明：你可以通过编写 Modelfile 来组合现有模型、添加系统提示词或调整参数，然后用这个命令生成自己的模型。

3. ollama show

  • 作用：显示某个模型的详细信息。
  • 说明：执行 ollama show <模型名> 可以查看该模型的参数大小、量化级别、创建时间等元数据。

4. ollama run

  • 作用：启动并运行一个模型，进入对话交互界面。
  • 说明：这是最常用的命令之一，例如 ollama run llama3 会自动下载（如果本地没有）并启动 Llama 3 模型，然后你就可以直接在终端中与模型聊天。

5. ollama stop

  • 作用：停止一个正在运行的模型。
  • 说明：当你用 run 启动模型后，它会在后台占用资源，用这个命令可以释放资源，例如 ollama stop llama3。

6. ollama pull

  • 作用：从 Ollama 的模型仓库中下载模型到本地。
  • 说明：例如 ollama pull qwen2 会把 Qwen2 模型下载到本地，之后就可以用 run 启动它。

7. ollama push

  • 作用：将本地的自定义模型推送到 Ollama 的远程仓库。
  • 说明：如果你用 create 制作了自己的模型，可以用这个命令上传到云端，方便在其他设备上使用。

8. ollama signin / ollama signout

  • 作用：登录 / 退出 Ollama 的账号。
  • 说明：登录后才能使用需要权限的功能，比如推送模型到远程仓库。

9. ollama list

  • 作用：列出本地已下载的所有模型。
  • 说明：执行后会显示每个模型的名称、大小和修改时间，让你清楚本地有哪些模型可用。

10. ollama ps

  • 作用：列出当前正在运行的模型。
  • 说明：可以查看哪些模型在后台占用资源，方便你用 stop 命令清理。

11. ollama cp

  • 作用：复制一个模型，创建一个副本。
  • 说明：例如 ollama cp llama3 my-llama3 会把 llama3 模型复制一份并命名为 my-llama3，方便你基于副本进行修改。

12. ollama rm

  • 作用：删除本地的一个模型。
  • 说明：当你不需要某个模型时，用这个命令可以释放磁盘空间，例如 ollama rm llama3。

13. ollama help

  • 作用：显示帮助信息。
  • 说明：可以跟具体命令一起使用，例如 ollama run --help 会显示 run 命令的详细用法和可选参数。

🚩 常用 Flags（选项）

  • -h, --help：显示 Ollama 的全局帮助信息。
  • -v, --version：显示当前 Ollama 的版本号。
